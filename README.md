# Мой помощник

Личный сайт-помощник. Чистый HTML/CSS/JS без сборки и сервера: все данные хранятся в браузере (localStorage), работает офлайн и ставится на телефон как приложение.

## Разделы
- **💱 Курсы и переводы** — сравнение способов вывода денег (через $, Paysend, Tenge Bank и свои цепочки) по итоговой сумме; режим «хочу получить N»; история сравнений; конвертер по рыночному курсу (open.er-api.com).
- **✅ Дела** — ввод фразой («завтра в 18:00 позвонить маме !», «каждый день …», «в пт … #тег»), режим «одна задача», случайная задача, таймер «просто начни 5 мин», перенос просрочки одной кнопкой, наборы задач, серия дней.
- **💼 Вакансии** — профиль навыков → поиск через API hh (KZ/UZ/RU) с оценкой совпадения, ссылки на другие площадки, шаблон сопроводительного, трекер откликов.
- **📈 Финансы** — 12 уроков, калькуляторы (50/30/20, сложный процент с графиком, подушка, кредит, цена привычки, цель), учёт расходов.
- **🍳 Рецепты** — отметь продукты → что можно приготовить и чего не хватает; недостающее одной кнопкой в Дела.
- **📖 Гайд** — значки на одежде с расшифровкой ярлыка, пятна, глажка, размеры, хранение продуктов, меры, уборка, первая помощь, безопасность и др., с поиском.
- **🧰 Мелочи** — привычки, вода, платежи и подписки, дни рождения, делёж счёта, решалка, помидор, дыхание, генератор паролей, заметки, конвертер единиц.
- **⚙️ Настройки** — имя, тема, резервная копия (экспорт/импорт JSON).

## Запуск
Открыть `index.html` в браузере, или локально:
```bash
python3 -m http.server 8000
```
Для публикации подойдёт GitHub Pages (Settings → Pages → ветка, папка `/`).

Курсы в шаблонах переводов — примерные: перед сравнением вписывай актуальные курсы и комиссии из своих приложений.
